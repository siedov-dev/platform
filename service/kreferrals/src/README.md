# Документация проекта KReferrals

## Обзор

Проект KReferrals представляет собой систему управления реферальными программами, построенную на Go с использованием микросервисной архитектуры. Система обеспечивает полный жизненный цикл реферальных операций: от обработки кликов по ссылкам до начисления наград и переводов средств.

## Архитектура проекта

Проект следует принципам Clean Architecture и разделен на следующие слои:

```
┌─────────────────────────────────────────────────────────────────┐
│                    Presentation Layer                          │
│                      (NATS Broker)                             │
├─────────────────────────────────────────────────────────────────┤
│                    Application Layer                           │
│                      (Use Cases)                               │
├─────────────────────────────────────────────────────────────────┤
│                     Service Layer                              │
│                 (Business Logic)                               │
├─────────────────────────────────────────────────────────────────┤
│                   Infrastructure Layer                         │
│              (Repository, Container)                           │
├─────────────────────────────────────────────────────────────────┤
│                      Data Layer                                │
│                     (Models)                                   │
└─────────────────────────────────────────────────────────────────┘
```

# 🔄 Поток данных

## Обработка событий пользователей

```
1. Внешняя система → NATS JetStream (userevents.*)
2. NATS Broker → User Events Handler
3. User Events → Use Cases
4. Use Cases → Service Layer (конфигурации)
5. Use Cases → Repository Layer (сохранение)
6. Use Cases → NATS RefWallet (начисления)
```

## Обработка запросов

```
1. Внешняя система → NATS Request (referrals.*)
2. NATS Broker → Callbacks Handler
3. Callbacks → Use Cases
4. Use Cases → Service/Repository Layers
5. Response ← NATS Broker ← Callbacks
```

# 🛠️ Технологический стек

## Основные технологии
- **Go 1.21+** - основной язык программирования
- **NATS** - брокер сообщений и JetStream

## Архитектурные паттерны
- **Clean Architecture** - разделение на слои
- **Repository Pattern** - абстракция доступа к данным
- **Use Case Pattern** - инкапсуляция бизнес-логики

## Принципы проектирования
- **SOLID** - принципы объектно-ориентированного программирования
- **DRY** - избежание дублирования кода

# 🚀 Быстрый старт

## Запуск системы

1. **Настройка конфигурации**:
   ```yaml
   # config/config.yaml
   nats:
     url: "nats://localhost:4222"
     token: "your-token"
   database:
     host: "localhost"
     port: 3306
     name: "kreferrals"
   ```

2. **Инициализация компонентов**:
   ```go
   // Инициализация сервисного слоя
   service.MustInit(ctx)
   
   // Инициализация NATS брокера
   natsbroker.MustInit(ctx)
   
   // Настройка контейнера зависимостей
   container.SetRepositories(...)
   ```

3. **Обработка событий**:
   ```go
   // Публикация события первого депозита
   js.Publish("userevents.first-dep", eventData)
   
   // Синхронный запрос получения реферального кода
   resp, err := nats.Request("referrals.getRefCode", requestData, timeout)
   ```
