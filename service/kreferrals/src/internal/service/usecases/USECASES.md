# Документация пакета Use Cases

## Обзор

Пакет `usecases` содержит бизнес-логику реферальной системы, реализованную в виде функций-сценариев использования (Use Cases). Каждая функция представляет собой отдельный бизнес-процесс и инкапсулирует логику взаимодействия с репозиториями, сервисами и внешними системами.

## Архитектура

Пакет следует принципам Clean Architecture:
- **Независимость от фреймворков**: Чистая бизнес-логика без привязки к конкретным технологиям
- **Тестируемость**: Каждый use case может быть протестирован изолированно
- **Разделение ответственности**: Каждая функция отвечает за один конкретный сценарий
- **Зависимость от абстракций**: Использование интерфейсов из пакета `container`

# Группы Use Cases

## 1. Обработка событий пользователей

### AchiveDone - Завершение достижения

**Файл**: [`achive_done.go`](achive_done.go)

```go
func AchiveDone(ref_id uint64, user_id uint64, ach_id uint64, currency string, currency_id int, fingerprint *string)
```

**Назначение**: Обрабатывает завершение достижения пользователем и начисляет награду рефералу.

**Параметры**:
- `ref_id` - ID реферала
- `user_id` - ID пользователя, выполнившего достижение
- `ach_id` - ID достижения
- `currency` - валюта награды (строка)
- `currency_id` - ID валюты (число)
- `fingerprint` - отпечаток пользователя

**Алгоритм**:
1. Получение ID владельца реферального кода
2. Проверка существования реферала
3. Получение размера награды за достижение
4. Начисление награды на реферальный баланс
5. Создание и сохранение события `ReferralEventTypeAchievementCompleted`

**Особенности**:
- Если награда равна 0, операция прекращается
- Данные события содержат `ach_id` и `currency`
- Прибыль равна размеру награды, сумма равна 0

**Файл**: [`firstdep.go`](firstdep.go)

```go
func FirstDep(ref_id uint64, user_id uint64, amount float64, currency string, currency_id int, fingerprint *string)
```

**Назначение**: Обрабатывает первый депозит пользователя и начисляет бонус рефералу.

**Параметры**:

- `user_id` - ID пользователя
- `amount` - сумма депозита
- `currency` - валюта депозита
- `currency_id` - ID валюты

**Алгоритм**:
1. Получение ID владельца реферального кода
2. Получение конфигурации пользователя

**Особенности**:

- Сохраняет ID конфигурации в событии
- Данные события содержат `amount` и `currency`

### MoneySpent - Трата денег

**Файл**: [`money_spent.go`](money_spent.go)

```go
func MoneySpent(ref_id uint64, user_id uint64, amount float64, currency string, currency_id int, fingerprint *string)
```

**Назначение**: Обрабатывает трату денег пользователем и начисляет процент на накопительный баланс реферала.

**Параметры**:
- `ref_id` - ID реферала
- `user_id` - ID пользователя
- `amount` - потраченная сумма
- `currency` - валюта
- `currency_id` - ID валюты
- `fingerprint` - отпечаток пользователя

**Алгоритм**:
1. Получение ID владельца реферального кода
2. Получение конфигурации пользователя
3. Расчет суммы для начисления: `ref_amount = config.GGRPrc * amount / 100`
4. Начисление на накопительный баланс реферала
5. Создание и сохранение события `ReferralEventTypeMoneySpent`

**Особенности**:
- Использует процент GGR из конфигурации
- Начисляет на накопительный баланс, а не на основной
- Данные события содержат `amount`, `currency` и `ref_amount`

### RefClick - Клик по реферальной ссылке

**Файл**: [`refclick.go`](refclick.go)

```go
func RefClick(ref_code string, referer string, fingerprint *string)
```

**Назначение**: Обрабатывает переход по реферальной ссылке и сохраняет событие клика.

**Параметры**:
- `ref_code` - реферальный код (строка)
- `referer` - источник перехода
- `fingerprint` - отпечаток пользователя

**Алгоритм**:
1. Поиск реферала по коду
2. Проверка существования и валидности реферала
3. Создание и сохранение события `ReferralEventTypeClick`

**Особенности**:
- Принимает строковый код, а не ID
- UserID в событии равен `nil` (анонимный клик)
- Данные события содержат `ref_id` и `referer`
- Не начисляет денежные средства

## 2. Управление реферальными кодами

### GetRefCode - Получение реферального кода

**Файл**: [`get_ref_code.go`](get_ref_code.go)

```go
func GetRefCode(user_id uint64) (*models.UserReferral, error)
```

**Назначение**: Получает существующий или создает новый реферальный код для пользователя.

**Параметры**:
- `user_id` - ID пользователя

**Возвращает**:
- `*models.UserReferral` - реферальный код пользователя
- `error` - ошибка выполнения

**Алгоритм**:
1. Поиск существующего реферального кода пользователя
2. Если найден - возврат существующего
3. Если не найден - генерация нового кода
4. Проверка уникальности кода (до 3 попыток)
5. Создание записи в базе данных
6. Возврат созданного реферала

**Особенности**:
- **Потокобезопасность**: Использует мьютекс для предотвращения гонки данных
- **Генерация кода**: 16 символов из набора `A-Z0-9`
- **Проверка уникальности**: До 3 попыток генерации уникального кода
- **Обработка ошибок**: Возвращает ошибку при невозможности создать уникальный код

**Константы**:
```go
const charset = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"
```

**Вспомогательная функция**:
```go
func generateRandomString(length int) string
```

### TransferAllAccumMoney - Массовый перевод накопительных средств

**Файл**: [`transfer_all_accum_money.go`](transfer_all_accum_money.go)

```go
func TransferAllAccumMoney() error
```

**Назначение**: Переводит все накопленные средства всех рефералов в системе.

**Возвращает**:
- `error` - ошибка выполнения

**Алгоритм**:
1. Получение всех реферальных кодов с пагинацией (по 500 записей)
2. Для каждого реферала:
   - Выполнение перевода всех накопленных средств
   - Обработка результата по валютам
   - Создание событий для каждой валюты
3. Продолжение до обработки всех рефералов

**Особенности**:
- **Пакетная обработка**: Обрабатывает по 500 рефералов за раз
- **Мультивалютность**: Создает отдельное событие для каждой валюты
- **Обработка ошибок**: Прекращает выполнение при первой ошибке
- **Логирование**: Подробное логирование процесса

**Константы**:
```go
limit := int64(500) // Размер пакета для обработки
```

# Общие паттерны и особенности

## Обработка ошибок

Все use cases следуют единому подходу к обработке ошибок:

```go
if err != nil {
    logger.Get().Error("Error description", "param", value, "error", err.Error())
    return // или return err
}
```

## Логирование

Используется структурированное логирование с библиотекой logger:

```go
logger.Get().Info("Operation", "param1", value1, "param2", value2)
logger.Get().Error("Error occurred", "error", err.Error())
```

## Создание событий

Стандартный паттерн создания событий:

```go
event := &models.ReferralEvent{
    UserID:      &user_id,
    RefID:       ref_id,
    Type:        int(models.ReferralEventType...),
    Data:        &jsonData,
    Amount:      amount,
    Currency:    &currency_id,
    Profit:      profit,
    CreatedAt:   nil, // Автоматически устанавливается в БД
    UpdatedAt:   nil, // Автоматически устанавливается в БД
    Status:      0,   // По умолчанию - ожидает обработки
    ConfigID:    configID,
    Fingerprint: fingerprint,
}
```

## JSON данные событий

Дополнительные данные событий сериализуются в JSON:

```go
data := map[string]any{"key": value, "key2": value2}
jsonData, err := json.Marshal(data)
if err != nil {
    logger.Get().Error("Error marshalling data", "error", err.Error())
}
var sjsonData string = string(jsonData)
```

## Валидация входных данных

Базовая валидация существования рефералов:

```go
if ref_user_id == 0 {
    logger.Get().Info("Referral code not found", "ref_id", ref_id)
    return // Прекращение выполнения
}
```

# Рекомендации по использованию

## Обработка событий пользователей

```go
// Обработка клика по ссылке
usecases.RefClick("ABC123", "https://example.com", &fingerprint)

// Регистрация пользователя
usecases.UserRegistered(refID, userID, &fingerprint)

// Первый депозит
usecases.FirstDep(refID, userID, 100.0, "USD", 1, &fingerprint)

// Трата денег
usecases.MoneySpent(refID, userID, 50.0, "USD", 1, &fingerprint)

// Завершение достижения
usecases.AchiveDone(refID, userID, achievementID, "USD", 1, &fingerprint)
```

## Получение данных

```go
// Получение реферального кода
referral, err := usecases.GetRefCode(userID)
if err != nil {
    // Обработка ошибки
}

// Получение событий с пагинацией
events, total, err := usecases.GetReferralEvents(refID, 0, 20)

// Получение пользователей реферала
users, total, err := usecases.GetReferralUsers(refID, 0, 20)
```

## Переводы средств

```go
// Перевод реферальных денег
transferred, err := usecases.TransferRefMoney(userID, "USD", 1)

// Перевод накопительных денег
transferred, err := usecases.TransferAccumulatedMoney(userID, "USD", 1)

// Массовый перевод всех накопительных средств
err := usecases.TransferAllAccumMoney()
```
