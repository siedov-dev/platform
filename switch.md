# Интерактивные мини-игры лояльности

Реализован набор из трех интерактивных мини-игр для системы лояльности пользователей (на React + Vite).
Все игры представлены в виде визуально насыщенных React-компонентов с использованием Framer Motion для анимаций и canvas-confetti для визуальных эффектов (праздничное конфетти при выигрыше).

## Состав:

1. **Колесо Фортуны (Wheel of Fortune)**
   - Интерактивное колесо с 8 секторами
   - Имитация API (`POST /api/wheel/spin`) через MSW
   - Анимация вращения колеса до выбранного сектора и модальное окно с результатом

2. **Игровой автомат (Slot Machine)**
   - Классический слот с тремя барабанами
   - Имитация API (`POST /api/slotmachine/spin`) через MSW
   - Анимация крутящихся символов и последовательной остановки барабанов

3. **Ежедневный сундук (Treasures)**
   - Сундук с наградами разной степени редкости (Common, Rare, Epic, Legendary)
   - Имитация API (`GET /api/treasures/open`) через MSW
   - Трехэтапная анимация: закрытый сундук -> тряска (открытие) -> появление награды в свечении

## Технический стек
- React (Vite)
- Tailwind CSS (стилизация)
- Framer Motion (плавные анимации, popup'ы)
- canvas-confetti (эффекты выигрыша)
- MSW (Mock Service Worker) для эмуляции API
- Vitest + React Testing Library для тестирования

## Тестирование
- Написаны unit/интеграционные тесты для каждого из компонентов, проверяющие рендеринг, взаимодействие с пользователем и вызовы мок-API.
